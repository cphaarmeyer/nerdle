
# nerdle

<!-- badges: start -->
<!-- badges: end -->

Solve the [nerdle](https://nerdlegame.com/).

To get started run [generate.R](generate.R) to generate all possible solutions and [commutative.R](commutative.R) to determine equivalent solutions due to commutativity.
Continue with the [evaluate.R](evaluate.R) script which you can adjust depending on your first guess and the color responses.

The [first.R](first.R) script is an attempt to find the best first guess.
I don't have a final result but "48-36=12" seems to be up there.
